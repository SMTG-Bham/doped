doped.io package
====================

Calculator-specific input/output code for ``doped``. Each supported
calculator has a ``doped.io.<calculator>`` subpackage with ``inputs``
(calculation input file generation) and ``outputs`` (output parsing) modules,
producing/consuming the calculator-agnostic
:class:`~doped.io.outputs.CalculationOutputs` data contract. See the
:ref:`Adding_Calculators:Adding Support for a New Calculator` page for
details on implementing support for additional calculators.
